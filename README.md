# Fn, FnMut, FnOnce в Rust

## Что такое трейты замыканий

**Замыкание** — **анонимный тип**, реализующий **один из трёх** трейтов:

| Трейт | Вызовов | Захват | `self` |
|---|---|---|---|
| **`FnOnce`** | **1** | Move | `self` |
| **`FnMut`** | **N** | `&mut` | `&mut self` |
| **`Fn`** | **N** | `&` | `&self` |

**Компилятор** **автоматически** выбирает **наиболее лёгкий** из **доступных** — исходя из того, **как** замыкание **использует** захваченные переменные.

## Иерархия

```
        FnOnce    ← самый широкий
          ↑
        FnMut
          ↑
         Fn       ← самый узкий
```

- **`Fn: FnMut: FnOnce`** — **вложенные** трейты.
- **`Fn`** → **автоматически** `FnMut` **и** `FnOnce`.
- **`FnMut`** → **автоматически** `FnOnce`.

## Разбор примера

### 1. `Fn` — захват по `&T`

```rust
let s = String::from("abc");
let f1 = || println!("{s}");   // Fn, захват по &T
f1();   // abc
```

- **Только читает** `s`.
- **`Fn`** — `&self`.
- **Можно** вызвать **много раз**.

### 2. `FnMut` — захват по `&mut T`

```rust
let mut v = vec![1, 2, 3, 4, 5];
let mut f2 = || {
    v.push(6);   // ← изменяет v
    println!("{v:?}");
};   // FnMut, захват по &mut T
f2();   // [1, 2, 3, 4, 5, 6]
```

- **Изменяет** `v`.
- **`FnMut`** — `&mut self`.
- **`f2`** — **`mut`** (нужен `&mut`).

### 3. `FnOnce` — захват по move

```rust
let f3 = || {
    drop(s);   // ← потребляет s
    println!("s has droped!");
};   // FnOnce, потребляет s
f3();   // s has droped!

// s;   // ❌ use of moved value
```

- **Потребляет** `s` (`drop`).
- **`FnOnce`** — `self`.
- **Только один** вызов.
- **После** — `s` **инвалидирован**.

### 4. `move` + `Copy` = `Fn`

```rust
let x = 2;
let f4 = move || drop(x);   // Fn, т.к. x: Copy
f4();
println!("x: {x}");   // x: 2
```

**Ключевое:** `x: Copy` → **`move`** **копирует** → `f4` — **`Fn`**, `x` **остаётся** валидным.

## Ключевое слово `move`

**`move`** **форсирует** захват **по значению**, **независимо** от того, **как** используются переменные.

### Без `move`

```rust
let s = String::from("abc");
let f = || println!("{s}");   // захват по &
```

### С `move`

```rust
let s = String::from("abc");
let f = move || println!("{s}");   // захват по move (владение)
```

**Разница:** замыкание **владеет** `s` (даже если только **читает**).

### `move` и `Copy`

```rust
let x = 2;
let f = move || drop(x);   // x: Copy → move копирует

println!("x: {x}");   // ✅ x доступен
```

- **`move`** **захватывает** `x` **по значению**.
- **`x: Copy`** → **копия** → `x` **остаётся** валидным.
- **`f`** — **`Fn`** (потому что `drop(x)` **не потребляет** оригинал — это **копия**).

## Подводный камень

> **`move` не делает замыкание `FnOnce` автоматически.**

**Тип трейта** определяется тем, **что** замыкание **делает** с захваченным. **`move`** только **меняет способ захвата**.

| `move` | Что делает с `T` | Трейт |
|---|---|---|
| ❌ | Читает | `Fn` |
| ❌ | Изменяет | `FnMut` |
| ❌ | Потребляет | `FnOnce` |
| ✅ + `T: Copy` | Читает | **`Fn`** |
| ✅ + `T: Copy` | Изменяет | `FnMut` |
| ✅ | Потребляет | `FnOnce` |

## Зачем `move`

**`move`** **нужен** для **`thread::spawn`** и **`tokio::spawn`**, потому что замыкание должно быть **`'static`** — **не** содержать **ссылок** из **стека** породившего потока.

```rust
let s = String::from("abc");

thread::spawn(move || {
    println!("{s}");   // ← move: владение в поток
});
```

**Без `move`:**

```rust
thread::spawn(|| {
    println!("{s}");   // ❌ ошибка: s может не дожить
});
```

**Ошибка:**

```
error[E0373]: closure may outlive the current function, but it borrows `s`,
              which is owned by the current function
```

## Сводная таблица

| Замыкание | Трейт | Захват | Вызовов |
|---|---|---|---|
| **`\|\| println!("{s}")`** | `Fn` | `&` | N |
| **`\|\| v.push(6)`** | `FnMut` | `&mut` | N |
| **`\|\| drop(s)`** | `FnOnce` | Move | 1 |
| **`move \|\| println!("{s}")`** | `Fn` | Move | N |
| **`move \|\| drop(s)`** | `FnOnce` | Move | 1 |
| **`move \|\| drop(x)`** (`x: Copy`) | **`Fn`** | Copy | N |

## Сводная таблица

| Аспект | `Fn` | `FnMut` | `FnOnce` |
|---|---|---|---|
| **Вызовов** | N | N | 1 |
| **`self`** | `&self` | `&mut self` | `self` |
| **Захват** | `&T` | `&mut T` | `T` |
| **Переменная** | — | `mut` | — |
| **Иерархия** | → `FnMut` → `FnOnce` | → `FnOnce` | — |

## Итог

- **Три трейта замыканий:** `Fn`, `FnMut`, `FnOnce`.
- **Иерархия:** `Fn → FnMut → FnOnce`.
- **`Fn`** → **автоматически** `FnMut` и `FnOnce`.
- **Компилятор** выбирает **наиболее лёгкий** трейт по **использованию**.
- **`move`** — **форсирует** захват **по значению**.
- **`move` + `Copy`** → **копия**, а **не** move.
- **Подводный камень:** `move` **не делает** замыкание `FnOnce`.
- **`move`** **нужен** для **`thread::spawn`** / **`tokio::spawn`**.
- **В вашем примере:**
  - `f1` — `Fn` (`&s`);
  - `f2` — `FnMut` (`&mut v`);
  - `f3` — `FnOnce` (`drop(s)`);
  - `f4` — `Fn` (`move` + `Copy`).
- **Правило:** тип трейта определяется **использованием**, а `move` — **способом захвата**.
